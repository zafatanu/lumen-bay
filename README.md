An original sun-soaked island crime game for the [make.fun](https://make.fun) gta6-01 bounty: steal cars, outrun the law and work eight story missions across the five districts of Lumen Bay. Drive traffic-heavy boulevards, shake police chases with the helicopter overhead, trade shots with the Gulls on foot, tune the synth radio and autosave your progress — all rendered live in your browser with no build step and no network requests.

Serve it locally with `node serve.ts`, then open http://localhost:8080. The game runs entirely offline from static files in desktop Chrome.

**Controls**

- `WASD` / arrows — drive or walk
- `SPACE` — handbrake (drift for cash)
- `F` — enter / steal a car
- `E` — interact, start a mission or side job
- `Click` — shoot · `1-4` — select weapon · `R` — reload
- `N` — cycle radio station
- `M` — full map
- `Esc` — pause
